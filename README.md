# SpendWise

SpendWise is a simple budgeting application that helps users calculate their remaining balance after expenses.

## What SpendWise Does

The application asks the user to enter their budget and expenses. It then calculates and displays the remaining balance in the browser console.

## JavaScript Concepts Used

- Variables
- Data types
- User input
- Number conversion
- Calculations
- Functions
- Console output

## Variables

Variables are used to store the budget and expenses.

## User Input

The application uses `prompt()` to collect the budget and expenses from the user.

## Calculations

The remaining balance is calculated by subtracting expenses from the budget.

## Functions

The `calculateBalance()` function is used to calculate the remaining balance.

## Displaying Results

The results are displayed in the browser console using `console.log()`.
